## 3. Proxmox storage reserving more Storage than needed by the VHDs

Unity VM with **400 GB** of virtual disk space. Without `discard` and thin provisioning properly aligned, the ZFS pool showed **546 GB** of space reserved for this VM (`refreservation=546G`). This led to unnecessary storage consumption and significantly faster filling of the total available space on the server.

### 3.1 What is the "Discard" option in Proxmox (ZFS storage)?

The **Discard** option enables **TRIM support** for the virtual disk of a VM. When enabled, it allows the guest operating system to inform the underlying ZFS storage when blocks are no longer in use (e.g., after deleting files).

---

### 3.2 Why is it important to enable Discard?

- **Reclaims unused space:** It helps ZFS **free up storage blocks** that are no longer needed by the VM, preventing unnecessary disk growth.
- **Improves performance:** Especially with SSD-backed ZFS pools, TRIM operations can improve I/O efficiency over time.
- **Better snapshot/dedup efficiency:** Less stale data means **smaller snapshots** and more effective deduplication/compression.
